# Channel format defaults

Per-channel starting points. A format cannot make a weak idea good; it can only stop a
strong one from being hard to read.

## Blog

- Default length: 600-900 words. Length follows the idea.
- Structure: problem → solution → worked example → benefits → resources.
- Technical posts: 3+ source links and a runnable code example.
- Open with the problem or the result, not with context the reader already has.

## YouTube script

- Default beats (spoken, approximate):
  - 0:00 hook: the problem or the surprising result
  - 0:15 problem: who has it and why it hurts
  - 0:45 solution: the approach
  - 2:00 demo: show it working
  - 4:00 benefits and trade-offs
  - 5:00 close: what to do next
- Default runtime: under 6 minutes spoken.
- Pattern break roughly every 20-40 seconds; vary pacing rather than cutting mechanically.
- Mark visual cues per beat (screen, slide, talking head).
- Every claim in the script still needs the sourcing rules from the skill body.

## Podcast outline

- Hook: first 30 seconds, one concrete promise.
- Main segment: 15-20 minutes, one through-line, at most three sub-points.
- Close: last 2 minutes, one action.
- Write for the ear: shorter sentences than prose, no tables, no unreadable URLs.

## SEO defaults

- Title: action + benefit, in the reader's words.
- Description: what the reader gets, in one sentence.
- Headings: one H1, descriptive H2s, no keyword repetition.
- Titles and descriptions are read by search summarisers as well as humans, so clarity
  beats keyword patterns. Do not optimise for a pattern at the cost of being understood.

## Compliance checks

- Platform policy: monetisation, copyright, disclosure of sponsorship.
- Quotes and third-party material: attributed, and within fair use.
- Numbers and dates: sourced, and dated.
